# OMOP visualisations for python

The [omopgenerics](https://github.com/darwin-eu/omopgenerics) R library outputs a summarised result format for many Darwin EU/OHDSI packages.
This library can wrangle some of the results into a tidier format, and do some plotting for some libraries.

The notebooks describe the development and contain some examples.
